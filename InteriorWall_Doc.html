01

ภาพรวมระบบและขั้นตอนการทำงาน (Workflow Lifecycle)

4 ระบบย่อยในการจัดการงานสถาปัตยกรรมภายในอาคารโครงสร้างเหล็กโมดูลาร์

⚠️

กฎเหล็กและข้อกำหนดสำคัญที่สุดของระบบ Interior Wall:

1. ยูนิตต้องมี Attribute position: ก่อนรันผนัง ให้มั่นใจว่าได้รันคำสั่ง Unit Position แล้ว เพื่อป้องกันข้อผิดพลาด undefined method 'include?' for nil:NilClass
2. จุด Origin ประตูต้องอยู่ระหว่างช่องว่างผนัง: ตำแหน่งกึ่งกลางของ Component ประตูต้องตกลงในช่องว่างระหว่างแผงผนัง ไม่เหลื่อมทับตัวเนื้อผนัง มิฉะนั้นระบบจะแจ้งเตือน Door's origin is outside the temporary wall
3. ห้ามข้ามขั้นตอน Partition: ต้องทำเรียงลำดับ Door Spec → Set Height → Split Partition → Code Partition → Build Partition เสมอ
4. ปิด Excel ก่อน Export CSV: ปิดไฟล์ .csv ที่เปิดค้างไว้ก่อนกด Export เพื่อป้องกันปัญหาถูกล็อกสิทธิ์การเขียนไฟล์ (Permission Denied)

สายงานที่ 1

3D Wall & Pipe Shaft

แปลงเส้น CAD 41 มม. เป็น Solid 3D (Single/Double Wall), เคลียร์เสาโครงสร้าง และแปลงท่อสุขาภิบาล

สายงานที่ 2

Interior Wall (IW)

ซอยโครงเหล็ก C-Stud / Box Frame ตามระดับความสูง Low, Normal, High, กรุแผ่น Smartboard และใส่แผ่น Joint

สายงานที่ 3

Partition Wall (PT)

วิเคราะห์สเปกประตู, ซอยแผง, ใส่รหัสโค้ด, สร้างแผง 3D, กำหนดแผง On-site, ใส่ข้อต่อ Joint และออกแท็กบอกมิติ

สายงานที่ 4

EE Punching & DWG

เจาะช่องบล็อกไฟฟ้า/แอร์ทะลุแผ่น Smartboard 3D, ตรวจสอบบล็อกตกขอบ, สร้างแบบ 2D Drawing และส่งออกไฟล์ CAD DWG

03

สถาปัตยกรรมและตรรกะการคำนวณเชิงลึก (Deep-Dive Logic)

ตรรกะการประมวลผลของโมดูล Ruby แต่ละไฟล์ในระบบ Interior

3.1 การสร้างผนัง 3D: Single Wall, Double Wall & Pipe Shaft (Heim_BuildWall.rb)

ระบบอ่านเส้น CAD ผนังที่มีระยะห่าง $41\,\text{mm}$ ($\text{Tolerance} \pm 0.5\,\text{mm}$) แล้วสร้าง Solid Face สี่เหลี่ยมผืนผ้าขึ้นรูปด้วย pushpull(-1000.mm, false):

  • Single Wall: จัดเก็บในเลเยอร์ 01-3dsinglewall กำหนดชื่อกลุ่มเป็น keta หรือ tsuma ทาสีวัสดุ 'singlewall'
  • Double Wall: จัดเก็บในเลเยอร์ 01-3ddoublewall สำหรับผนังคู่ระหว่างยูนิต
  • Opening Clearance: ฟังก์ชัน Opening.clearsingleatcolumn() จะยิงตรวจสอบขอบเขตเสาเหล็กของยูนิต และตัดรอนเนื้อ Single Wall ไม่ให้วิ่งล้ำเข้าไปทับเสา
  • Pipe Shaft: คำสั่ง PipeShaft.movesingletopipeshaft() จะย้ายผนังชิ้นที่เลือกออกจากหมวดผนังห้องทั่วไป เพื่อไม่ให้ถูกนำไปซอยเป็นแผง Partition

3.2 ระบบโครงเหล็กและแผ่นสมาร์ทบอร์ดผนังใน (Heim_InFrame.rb & Heim_InBoard.rb)

กำหนดระดับความสูงตามรหัสยูนิตใน $hunitheight:

Low (L):
โครงเหล็ก inframe: 2,540 mm
แผ่นบอร์ด inboard: 2,544 mm
Normal (N):
โครงเหล็ก inframe: 2,810 mm
แผ่นบอร์ด inboard: 2,815 mm
High (H):
โครงเหล็ก inframe: 3,210 mm
แผ่นบอร์ด inboard: 3,223 mm

ตรรกะช่องเปิดหน้าต่าง ($iwframe): สคริปต์จะคำนวณระดับความสูงยกพื้น ($e$) และความสูงช่องเปิด ($height$) เช่น HI-Z ($e=0, H=2290$), HI-WAIST ($e=722, H=1518$), TATAKI ($e=0, H=2206$) เพื่อตัดทอนโครงเหล็กและฉลุแผ่น Smartboard ตามรูปทรงช่องเปิดอัตโนมัติ

3.3 ตรรกะการวิเคราะห์แผง Partition และช่องเปิดประตู (Heim_PtMain.rb)

หัวใจสำคัญในการคำนวณตำแหน่งประตูอยู่ที่ฟังก์ชัน gettempwallbetweendoor(door, point, isketa):

// การตรวจสอบพิกัด Origin ของประตูเทียบกับขอบเขตผนังชั่วคราว
samewall[index-1][1] < point.x && point.x < samewall[index][0]
- samewall[index-1][1] คือ จุดสิ้นสุดของผนังชิ้นซ้าย (หรือชิ้นล่าง)
- samewall[index][0] คือ จุดเริ่มต้นของผนังชิ้นขวา (หรือชิ้นบน)
- point คือ พิกัดกึ่งกลาง/Origin ของตัว Component ประตู

หากมีผนังน้อยกว่า 2 ชิ้น (samewall.length < 2) หรือพิกัด point ล้ำออกนอกช่องว่าง ระบบจะคืนค่า nil และแจ้งเตือนข้อผิดพลาดทันที

การแก้ไขปัญหาที่พบบ่อย (Troubleshooting & FAQs)

แนวทางการวิเคราะห์และแก้ไข Error ที่เกิดขึ้นในการทำงานจริง

Door's origin is outside the temporary wall

สาเหตุ: จุด Origin ของประตูไม่ได้ตกลงในช่องว่างระหว่างผนังชั่วคราว เช่น วางประตูเหลื่อมทับตัวเนื้อผนัง, หรือมีผนังในแนวนั้นน้อยกว่า 2 ชิ้น

✅ วิธีแก้: ตรวจสอบแนว Single Wall ซ้าย-ขวาของประตู, ขยับจุดกึ่งกลางประตูให้ลงช่องว่างพอดี, และตรวจสอบ Attribute ทิศทางเปิดประตู (U, D, L, R)

undefined method 'include?' for nil:NilClass

สาเหตุ: มียูนิตในเลเยอร์ S-Unit ที่ยังไม่มี Attribute position ทำให้ $dcposborder[nil] ได้ค่า nil

✅ วิธีแก้: ครอบยูนิตทั้งหมดแล้วรันคำสั่ง Unit Position ใหม่ หรือเติม || [] ในไฟล์ Heim_BuildWall.rb:626

Some walls do not have wall code...

สาเหตุ: กดปุ่ม Build Partition โดยที่ยังมีแผงผนังบางชิ้นยังไม่ได้รับการวิเคราะห์ใส่รหัสโค้ด

✅ วิธีแก้: กดปุ่ม Code Partition ก่อน เพื่อให้ระบบใส่โค้ดบนแผงชั่วคราวให้ครบทุกชิ้น แล้วจึงกด Build Partition ซ้ำอีกครั้ง

บล็อกไฟฟ้าแสดงสีเตือน (Off-board Block)

สาเหตุ: บล็อกไฟฟ้าตัวนั้นวางเหลื่อมล้ำออกนอกขอบแผ่น Smartboard ทำให้ระบบ Raytest ไม่สามารถเจาะทะลุแผ่นบอร์ดได้

✅ วิธีแก้: ขยับบล็อกไฟฟ้าให้เข้ามาอยู่ภายในพื้นที่ของแผ่น Smartboard หรือตรวจสอบว่าแผ่น Smartboard บริเวณนั้นถูกสร้างขึ้นเรียบร้อยแล้ว
