01

ภาพรวมระบบและขั้นตอนการทำงาน (Workflow Lifecycle)

จุดเริ่มต้นของกระบวนการถอดแบบ BIM ในโมดูลาร์ยูนิต QHeim

⚠️

กฎเหล็กสำคัญ 3 ข้อก่อนเริ่มนำเข้าไฟล์ CAD AR:

  • จุด Origin (0,0,0) ใน AutoCAD ต้องเป็นจุดอ้างอิงเดียวกันทุกชั้น (1F, 2F, 3F): ห้ามขยับหรือ Move แปลนหนีจุดกำเนิดเด็ดขาด มิฉะนั้นแต่ละชั้นจะไม่ซ้อนทับกัน
  • ต้องรัน VBA Macro ส่งออกข้อความ Text เป็น JSON ใน AutoCAD ก่อนเสมอ: รัน Macro เพื่อสร้างไฟล์ C:/QHeim/DATA/export-text.json มิฉะนั้นตัวหนังสือจะไม่เข้า SketchUp
  • ลำดับการกดปุ่มใน SketchUp ต้องเรียงตามลำดับ: Import CAD Original → Unit Number → Door Window Name
ขั้นตอนที่ 1 AutoCAD

เตรียมไฟล์และส่งออก JSON

ขั้นตอนที่ 3 SketchUp

ซิงค์ชื่อช่องเปิดและงานระบบ

05

สถาปัตยกรรมและตรรกะเชิงลึก (Code Architecture)

อธิบายการทำงานเชิงเทคนิค อัลกอริทึม และสูตรคำนวณเบื้องหลัง

1. ตัวเลือกการนำเข้า DWG (Preserve Origin Options)

ในไฟล์ Heim_InsertCADLTF.rb ระบบกำหนด Options เพื่อบังคับให้ SketchUp นำเข้าตามพิกัดจริงของ AutoCAD โดยไม่มีการเลื่อนตำแหน่ง: 

options = {
  :units => "mm",                  # บังคับหน่วยมิลลิเมตรให้ตรงกับ AutoCAD UNITS
  :merge_coplanar_faces => false,  # ไม่ยุบระนาบ เพื่อรักษาความสมบูรณ์ของเส้น
  :show_summary => false,          # ปิดกล่องข้อความสรุปของ SketchUp
  :preserve_origin => true         # หัวใจสำคัญ: ยึดจุดกำเนิด WCS (0,0,0) ป้องกันการเซ็ตเข้ากึ่งกลางอัตโนมัติ
}
status = model.import(dwg_path, options)

2. การแปลง Anchor และสร้าง 3D Text ภาษาไทยจาก JSON

เนื่องจาก 3D Text ของ SketchUp กำหนดจุดกำเนิดที่มุมล่างซ้ายเสมอ สคริปต์จึงคำนวณเวกเตอร์ Translation ย้อนกลับตามจุด Anchor ที่บันทึกมาจาก AutoCAD:

การคำนวณความสูงและระยะบรรทัด:
$$\text{Text Height} = \text{Height}_{\text{JSON}} \times 2.0$$ $$\text{Line Offset}_i = [0, -\text{LineSpacing} \times i, 0]$$
Transformation Matrix:
$$\mathbf{T}_{\text{final}} = \mathbf{T}_{\text{point}} \times \mathbf{R}_{\text{rotation}} \times \mathbf{T}_{\text{anchor}}$$ หมุนรอบแกน Z_AXIS และเลื่อนไปพิกัดจริง x, y, z

3. อัลกอริทึมจับคู่บล็อกช่องเปิดและต่อท้ายทิศทาง (_L / _R)

การทำงานใน Heim_DoorNameLTF.rb มีขั้นตอนคำนวณ 3 ขั้นตอน:

1. Merge Same-Line: ตรวจสอบทิศทาง xaxis.angle_between น้อยกว่า 5 องศา และระยะแกน Y ต่ำกว่า 20 มม. จึงรวมเป็นข้อความเดียวกัน
2. Distance Matching: คำนวณระยะทางแบบ Euclidean Distance ระหว่างบล็อก 2D กับข้อความ: $$\Delta = \sqrt{(x_d - x_t)^2 + (y_d - y_t)^2} < 0.90\,\text{m}$$
3. Direction Vector (checkOpen): ตรวจสอบเวกเตอร์ของกรอบบานเทียบกับขอบเขต Bounding Box ของยูนิตเพื่อกำหนดทิศทางบานสวิง: WW1222 + _R → WW1222_R

แนวทางแก้ไขปัญหาที่พบบ่อย (Troubleshooting Guide)

วิธีวินิจฉัยและแก้ปัญหาที่มักพบในงานเตรียมและนำเข้าไฟล์ CAD AR

1. แปลนแต่ละชั้นนำเข้าแล้วไม่ตรงกัน (ชั้น 1 กับชั้น 2 เหลื่อมกัน)

สาเหตุ: จุดกำเนิด Origin (0,0,0) ใน AutoCAD ของทั้งสองไฟล์ไม่ได้อยู่ที่ตำแหน่งเสาเดียวกัน หรือเกิดการ Move ย้ายแปลนหลังจากเขียนเสร็จ

วิธีแก้: เปิดไฟล์ AutoCAD ทั้งสองชั้น ใช้คำสั่ง ID คลิกที่จุดตัดมุมเสาอ้างอิงหลัก (เช่น เสา 1-A) ว่าได้พิกัด X=0, Y=0, Z=0 หรือไม่ หากไม่ตรง ให้ใช้คำสั่ง MOVE แปลนทั้งหมดโดยใช้จุดตัดเสานั้นเป็น Base Point แล้วพิมพ์พิกัดปลายทางเป็น 0,0,0 จากนั้น Save ไฟล์แล้ว Import เข้า SketchUp ใหม่

2. ตัวหนังสือภาษาไทยไม่ปรากฏ หรือขึ้นเตือน "CAD text JSON file not found"

สาเหตุ: ยังไม่ได้สั่งรัน VBA Macro ใน AutoCAD หรือรันแล้วแต่เกิดข้อผิดพลาดในการเขียนไฟล์ C:/QHeim/DATA/export-text.json

วิธีแก้: กลับไปที่หน้าต่าง AutoCAD ตรวจสอบว่าเปิดไฟล์แปลนอยู่ แล้วพิมพ์คำสั่ง VBARUN → เลือก ExportAllText_ForSketchUp_Anchored → รอจนมี Popup ยืนยันยอดจำนวนตัวอักษร แล้วค่อยกลับมากดปุ่ม Import CAD Original ใน SketchUp

3. สระหรือวรรณยุกต์ภาษาไทยอ่านไม่ออกหรือเพี้ยน (Encoding Issue)

สาเหตุ: การเข้ารหัสไฟล์ข้อความไม่ตรงกันระหว่างระบบ Windows ANSI กับ UTF-8

วิธีแก้: สคริปต์ Heim_InsertCADLTF.rb เวอร์ชันล่าสุดได้รับการปรับปรุงให้อ่าน Byte Order Mark (UTF-16LE, UTF-8) อัตโนมัติ หากยังพบปัญหา สามารถเปิดไฟล์ C:/QHeim/DATA/export-text.json ด้วย Notepad แล้วกด Save As → เลือก Encoding เป็น UTF-8 with BOM

4. บล็อกประตู-หน้าต่างไม่เปลี่ยนชื่อ หรือไม่ต่อท้ายทิศทาง (_L / _R)

สาเหตุ: 1. ตัวหนังสือไม่ได้อยู่ในเลเยอร์ A-ANNO-DOOR หรือ A-ANNO-WIND
2. บล็อก 2D ไม่ได้อยู่ในเลเยอร์ A-DOOR หรือ A-WIND
3. ระยะห่างระหว่างตัวหนังสือกับบล็อกไกลเกินระยะ Tolerance 0.90 เมตร

วิธีแก้: ตรวจสอบเลเยอร์ของวัตถุทั้งสองชิ้นให้ถูกต้อง หากเลเยอร์ถูกต้องแต่วางข้อความห่างเกินไป ให้เลื่อนข้อความเข้ามาใกล้จุดศูนย์กลางของบล็อกบาน แล้วกดปุ่ม Door Window Name ซ้ำอีกครั้ง

5. กด Unit Number แล้วไม่เกิดกลุ่มในเลเยอร์ S-Unit

สาเหตุ: ข้อความตัวเลขยูนิตในเลเยอร์ A-ANNO ไม่ได้อยู่ภายในพื้นที่สี่เหลี่ยมกริดของ EE-GRID-UNIT หรือรูปแบบข้อความไม่ได้เป็นตัวเลข

วิธีแก้: ตรวจสอบว่าตัวหนังสือระบุชื่อยูนิตต้องเป็นตัวเลขล้วน (เช่น 01, 02) หรือขึ้นต้นด้วยตัว H (เช่น H01) และตำแหน่งตัวหนังสือต้องวางอยู่ภายในกรอบสี่เหลี่ยมกริดของยูนิตนั้นๆ
